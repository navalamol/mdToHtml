## UX Changes by Domain

### Product Intake (Inbound Staging Catalog)
- New **Inbound Staging Catalog tab** added to the Product Intake (`/vendor-product-onboarding`) sidebar.
- Tab renders a searchable, filterable table of all inbound products across ingestion sources: GDSN, Vendor Portal, Email Intake, API/SFTP, CSV Upload, Syndigo Marketplace.
- Each row shows: SKU, product name, vendor, category, data source (color-coded badge), status badge, and a completeness progress bar.
- Four status states: **Ready to Publish** (green), **Needs Review** (amber), **AI Enriching** (primary/blue — animated), **Duplicate Match** (purple).
- Filters: source dropdown, category dropdown, status dropdown; keyword search across name/SKU/vendor.
- Download button (export placeholder).

### Navigation Config
- `navigation-config.ts` updated to add `inbound-staging` entry to the `vendor-onboarding` module sub-tabs list, with label "Inbound Staging Catalog" and `PackageSearch` icon.
